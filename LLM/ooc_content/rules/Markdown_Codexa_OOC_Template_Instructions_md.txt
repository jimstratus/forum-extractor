
# 🧠 Codexa Integration: Out-of-Character (OOC) Documentation Support

## 📘 Overview

Codexa now supports generating **OOC document templates** used for administrative purposes, GM rulings, announcements, and gameplay support.

This complements the in-universe document generation and provides OOC structure for organized roleplay, communication, and moderation.

---

## 📋 Supported OOC Templates

| Type         | Function            | Description |
|--------------|---------------------|-------------|
| Announcement | renderAnnouncement  | Official OOC messages to players |
| GM Decision  | renderGMDecision     | GM rulings or conflict resolution logs |
| Rules Update | renderRulesUpdate    | Updates to game rules and systems |
| Event Notice | renderEventNotice    | Upcoming event briefings for player sign-up |
| Admin Log    | renderAdminLog       | Admin actions: bans, warnings, audits |

---

## 🧾 Expected Behavior

When users say things like:
- “Post an OOC announcement”
- “Log a GM decision”
- “Update the rules”
- “Announce an event”
- “Record an admin action”

Codexa will:
- Ask for the appropriate fields if not provided
- Generate `#invoke:OOCDocBuilder|[function]` wikitext
- Maintain formal and structured output formatting

---

## 🧩 Sample: GM Decision

```
{{#invoke:OOCDocBuilder|renderGMDecision
 | id        = GM-DEC-20250410-002
 | gm        = GM Thalos
 | date      = 2025-04-10
 | player    = PlayerX
 | issue     = Dispute over RP resolution
 | decision  = Scene stands as played
 | rationale = Logs reviewed, confirmed no breach
 | status    = Final
}}
```

---

## 🧠 Instruction Rules

- Output uses `OOCDocBuilder` not `ImperialDocBuilder`
- Maintain clear section headers and formatting
- Dates should follow standard Earth format: YYYY-MM-DD
- Use `OOC-ANN-`, `GM-DEC-`, `RULE-UPD-`, `EVT-NOT-`, and `ADM-LOG-` prefixes

---

## 🔌 Deployment Notes

Codexa can generate these via:
- GPT interface (natural command → filled template)
- UI wizard (form fields)
- Future: MediaWiki integration via Special:Import

## ✅ Codexa Prompts to Recognize

| Prompt | Action |
|--------|--------|
| “Make an OOC announcement” | Generate `renderAnnouncement` template |
| “GM ruling on...”          | Generate `renderGMDecision` template |
| “Change the rules for...”  | Generate `renderRulesUpdate` template |
| “Host an event...”         | Generate `renderEventNotice` template |
| “Log a ban/kick/etc.”      | Generate `renderAdminLog` template |
