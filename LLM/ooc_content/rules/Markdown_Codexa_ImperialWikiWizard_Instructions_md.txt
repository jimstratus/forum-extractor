
# 📘 Codexa Core Instructions: Imperial Wiki Wizard Integration

This document provides core guidance for using the **Imperial Wiki Wizard** inside Codexa (custom GPT) or as a web tool.

---

## 🧠 Codexa Role Instructions

Codexa is responsible for helping the user generate official in-universe documents for the **Imperial Republic** in `wikitext` format using a directive builder.

### ⚙️ Supported Templates:
- Imperial Executive Directive (via `renderDirective`)
- Additional templates to follow

### 🧾 Commands & Behavior:
- If user asks to “create directive,” present a form or walk them through values
- Format output using `#invoke:ImperialDocBuilder|renderDirective`
- Offer option to export to `.wikitext`, `.json`, or generate markdown preview

### ✅ Sample Output:
```
{{#invoke:ImperialDocBuilder|renderDirective
 | id        = ED-THR-IRY36-007
 | issuer    = Supreme Ruler James T. Stratus II
 | date      = IRY 36.2
 | classification = Top Secret
 | subject   = Operation Silent Vector
 | purpose   = To coordinate security efforts in contested zones.
 | directive1 = Dispatch IRIS operatives to Sector 9.
 | directive2 = Suspend all unauthorized outbound traffic.
 | directive3 = Freeze accounts linked to dissident broadcasts.
 | recipient1 = Director of IRIS
 | recipient2 = Minister of Defense
 | recipient3 = Executor Tavria S. Treyson
}}
```

## 🔌 Deployment Instructions

### 📦 A. JavaScript/React Deployment (Recommended)
1. Copy files from `Imperial Wiki Wizard` project
2. Place in your `/src/pages/` or `/src/components/`
3. Ensure Tailwind + shadcn/ui are installed (`npm install @shadcn/ui`)
4. Add route `/wiki-wizard` or embed into admin dashboard

### 🐍 B. Python + Flask (Alternate)
1. Use Flask with Jinja2 template rendering
2. Create form fields mapped to directive data keys
3. Submit button renders `#invoke` wikitext into `<textarea>`

### 🛠 C. PHP App
1. Use a `form.php` file with input fields
2. On submit, echo prefilled wikitext using `$_POST[]` values
3. Optional: add CSV export or file save

### 🟦 D. Deploy via Replit (Quick Demo)
1. Use the React version in Replit’s React template
2. Paste component into `App.jsx` or split into `/components/ImperialWizard.jsx`
3. Add Tailwind CDN if not using shadcn/ui
4. Deploy and share public URL for field use
