
# 🧠 Out-of-Character (OOC) Document Codification System

## 📘 Format

```
[DOCTYPE]-[AUTHOR/ORG]-[YYYYMMDD]-[SEQ|REV]
```

| Segment      | Meaning                               | Example         |
|--------------|----------------------------------------|-----------------|
| `DOCTYPE`    | Document type                          | `PLAN`, `NOTES` |
| `AUTHOR/ORG` | Author initials, alias, or org name    | `JS`, `DOC`, `TAP` |
| `YYYYMMDD`   | Date of creation or major revision     | `20250410`      |
| `SEQ/REV`    | Optional sequence or revision tag      | `v1`, `rev2`    |

---

## 📂 Document Type Codes

| Code    | Type                              |
|---------|-----------------------------------|
| `PLAN`  | Planning document                 |
| `SPEC`  | Specification or requirement      |
| `NOTES` | Notes or brainstorming content    |
| `DRAFT` | Draft version of a doc            |
| `CHAT`  | Chat logs, GPT transcripts        |
| `IMG`   | Concept art or stamp mockups      |
| `REF`   | Reference materials or citations  |
| `RULES` | Out-of-character rulesets         |
