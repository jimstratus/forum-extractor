IRIN PROJECT 

 

Description: This project is to be a series of scripts or applications interacting with a MySQL database to serve as a catalog or database of Orders concerning all orders and directives made by personnel in the Imperial Republic including but not limited to, government agencies, the military, private orders, executive orders, directives, etc. This database is to have access for registered users only, having been added by an administrator and all data be restricted by security clearance classifications. 

 

Definitions & Terminology 

 

Security Clearances: 

All users will be assigned a security clearance that shall be part of their account information editable only by an admin. Personnel with a security clearance are able to access information that is restricted to their clearance level, and all levels below it. The following security clearances exist, in order of greatest to least, with military rank restrictions: 

	 	Alpha Blue 

This security clearance is the highest and is usually reserved for the Supreme Ruler only. 

Grade restrictions: C-5 or higher,  as designated by Supreme Ruler. 

 

	 	Alpha Green 

This security clearance is restricted to members of Royal High Command, each clearance issued of this type must be approved and issued by the Throne. Grade restrictions: O-6 or higher, as designated by the Throne. 

 

	 	Delta Red 

This security clearance is for Intelligence and the Security Bureau. It may be granted to military officers. 

Grade restrictions: Security/Intelligence personnel as designated by said departments, otherwise O-4 or higher. All members of the High Council hold this clearance at minimum. 

 

	 	Delta Green 

This security clearance is for the Upper Echelon of the Military, for higher ranking military officers and special or command units. These clearances may be granted to military personnel at the discretion of military commanders who posses them or higher, when situations require or validate such course of actions. Grade restrictions:  O-4 or higher. 

 

	 	Epsilon 

This security clearance is for regular military personnel who are assigned a clearance. Most military personnel hold this clearance, however there are some cases where they hold none. Grade restrictions: E-5 or higher. 

 	 

	 	Civilian 

This is for anyone who does not hold a security clearance. It is the same as ‘None.” 

 

 

IRIN ID Numbers: 

All documents or orders are assigned a six-digit IRIN ID Number, generated by the script, (also known as an Order Number or Order ID). To better classify documents, each one will have a prefix based on the category chosen for the type of document. IRIN ID Prefixes or types follow: 

	 	C – Supreme Command (issued by Supreme Ruler Only) 

	 	E – Executive Order (issued by member of Royal High Command) 

	 	D – Defense (for all military documents and orders) 

	 	I – Intelligence (for all intelligence documents, operations, and orders) 

 	S – Security (for all security documents, operations, and orders) G –Government (for all government documents, operations, and orders) 

F – Financial (for all financial documents, operations, and orders) B – Business (for all non-government business or industrial documents, operations, and orders) 

P – Private (for all non-government personal documents, operations, and orders) 

 

Scripts/Application Sections, Views, and Details 

 

Login Page: This page will be the front page, requiring a user ID number (not a username), and security code (password or pin number). 

 

Login IDs: Login IDs are assigned as a number that increases by one each time a user is created. It is assigned by the script and cannot be modified.  

 

First Screen Logged In: This will show “Logged in as registered name and Clearance: Clearance of registered account” at the top middle of the screen, above the page title. 

 

Menu Options: Menu options will be displayed as links below the title of any page. They shall consist of based on access, User Info, IRIN Documents, Security Clearances, Manage Users. 

 

User Info: The user info page, for all users, will allow them to edit their security code and e-mail address only. It will display their current Login ID, Security Clearance, and rank. 

 

Security Clearances: This page view will list all users and their security clearances for people who have a security clearance Delta Green or higher, and will only list users of the same clearance or lower clearances. This is view only, not for editing. It shows user’s registered ‘rank, name, e-mail and Security Clearance’ only. 

 

Manage Users: This screen is restricted to an admin. It will show a table of all users, with their ID, rank, name, Security Clearance, and e-mail, and have an EDIT or DELETE button next to each user, allowing the admin to edit the following info for the selected user:  Security Code, e-mail address, security clearance, name, rank, and whether or not they have admin access. There will also be a button to add a new user, in which the fields above will be required to be entered and an ID automatically generated.  

 

IRIN Documents: Sub-Menu: This menu will have “View Documents, Find 

Document/Order, and Create Document/Order.” 

IRIN Documents: Main Screen (View Documents): This screen will list all orders/documents ASSIGNED to the user. (Documents can be assigned to multiple users.) It will also list all orders/documents, CREATED BY the user. They will be displayed in a table, sorted by date descending, and be displayed in the format “IRIN ID, 

DOCUMENT/ORDER NAME, STATUS, CREATOR, SECURITY CLEARENCE, and 

DATE”. All orders assigned or created by the user, reguardless of clearance, will be displayed. By clicking on the IRIN ID, the document/order will open in a view of only that document or order, with option of signing orders for those of higher rank, and editing the orders for those who signed it or with admin access. Those with Delta Red or admin access will display all orders with their clearance or lower. 

 

IRIN Documents: Document View: The document/order will open in a view of only that document or order, with option of signing orders for those of higher rank, and editing the orders for those who signed it or with admin access. Status may be updated by anyone assigned to the order, signed the order, or created the order. Creators of orders automatically are signatories of orders. 

 

IRIN Documents: Statuses: The following statuses may be assigned to any order, limited to one status. “For Review, Completed, Revoked, New, In Progress, Permanent” 

 

IRIN Documents: Find Document: This page will allow the user to type the IRIN Number and display any document matching the exact IRIN Number if their security clearance matches that of the document or is higher, unless assigned to or created by the user. 

 

IRIN Documents: Create Document/Orders: This will allow a user of higher rank to create a document or orders of a security clearance and category. After the orders or document is created, the creator is automatically added as a signatory and is taken to the view page of the document. Creators viewing a document they created may add assignees by entering the name of the user and clicking “assign user”.
