C.O.D.E. SYSTEM
Command Operations Declare Emergency
For use by Royal Guard and High Command and their Security Details
SECURITY PROTOCOL S444605
Integrate with IRIN maybe? Need php programmer for that.
FORMAT For TRANSMISSION OF CODE ALARM
MESSAGE:
CODE (#HERE) (TARGET/OR GROUP/INDIVIDUAL) (LOCATION) (GROUP/UNIT/INDIVIDUAL RECIPIENTS) (DATE) (SENDER)
WHO CAN SEND CODE ALARMS: RG, PSA, IRIS, IRSB, MOD, HC, THRONE, RF, HMPS
CODE NO. | ALARM DESCRIPTION
CODE 1 | DEATH OF PROTECTEE
CODE 2 | GUARDS DOWN
CODE 3 | DIRECT ATTACK/ENGAGEMENT OF PROTECTEE OR PALACE
CODE 4 | DETONATOR/EXPLOSIVES THREAT/DISCOVERY
CODE 5 | PROTECTEE MISSING
CODE 6 | MEDICAL EMERGENCY (PROTECTEE DOWN - NOT DEAD)
CODE 7 | BETRAYAL/INFILTRATION OF SECURITY OR TRUSTED INDIVIDUALS
CODE 8 | COMMUNICATIONS JAMMING OF PROTECTEE'S AREA
CODE 9 | IMPENDING THREAT AGAINST PROTECTEE
CODE RED | HIGH SECURITY ALERT ALL UNITS/LOCKDOWN/LOCAL MILITARY UNITS TO RED STATUS
CODE YELLOW | HEIGHTENED SECURITY ALERT (LOWER THAN RED) TO ALL UNITS
CODE GREEN | ALL CLEAR - CALL OF SECURITY ALERTS
