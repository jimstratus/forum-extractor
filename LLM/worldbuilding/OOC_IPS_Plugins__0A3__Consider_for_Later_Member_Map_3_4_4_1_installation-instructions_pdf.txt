Member Map 3  
 
Upgrading from ` Member Map ` 1.x OR 2.x  (IP.Board 3)  
 
1. Hover over `System`, click `Applications`  
2. Scroll down to the `Out of date applications` section  
3. Click `Upload a new version` on the ‘ membermap ’ row  
4. Select the .TAR file that is included with this document  
5. Click Install  
  

Upgrading from ` Member Map ` 3.x (IPS4)  
 
1. Hover over `System`, click `Applications`  
2. Expand the menu for Member Map  
3. Click `Upload a new version`  
4. Select the .TAR file that is included with this document  
5. Click Install  
Installing for the first time  
 
1. Hover over `System`, click `Applications`  
2. Click the blue Install button   
3. Select the .TAR file that is included with this document  
4. Click Install
